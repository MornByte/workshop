第 9 课 · 社团报名小助手：代码知识点练习

同样点「看看我能不能报」，换一项选择，网页就要给出不同结果。 这一课从一个下拉框开始，练习把选项变成真假、把真假变成有理由的结论。

你已经用过 .value 读取控件的值、用 textContent 更新页面。 各题已备好页面和点击监听。复制本题的整个起始文件夹，在自己的副本里改 app.js。 四题彼此独立，开始下一题时复制对应的新文件夹即可。 先读中文伪代码，想清楚程序要做什么。再照「编写代码」里的 JavaScript 动手。

01 读选项得真假

基础下拉框显示「零基础」和「有点基础」。jiChuKuang.value 读出当前选项的拼音值， 分别是 "lingJiChu" 和 "youDianJiChu"。

中文伪代码

读出基础选项的值
比较读到的值是否等于「有点基础」的选项值
显示读到的值和比较结果

编写代码

打开 app.js，在 // 01 · 读取与比较 下方写下面四行代码。 以 // 开头的是注释，写给读代码的人看，JavaScript 运行时会跳过它们。

// 用 .value 读出基础下拉框的选项值。
const jiChuZhi = jiChuKuang.value;
// 和「有点基础」的选项值比较，把真假存下来。
const youDianJiChu = jiChuZhi === "youDianJiChu";
// 把拼音值显示在「读到的值」一栏。
duDaoDeZhi.textContent = jiChuZhi;
// 把真假显示在「比较结果」一栏。
biJiaoJieGuo.textContent = youDianJiChu;

第一行把读到的文字存入 jiChuZhi。第二行用 === 比较值和类型， 把 true 或 false 存入变量 youDianJiChu。这两个真假值叫布尔值。 最后两行把读到的值和比较结果写到网页的两处结果里。

运行检查

选择基础后点击「读取基础」 读到的值 比较结果
有点基础 youDianJiChu true
零基础 lingJiChu false

把比较右边的 "youDianJiChu" 暂时改为 "lingJiChu"。 保存刷新，再做同样两次操作。读到的拼音值仍对应你的选择，两个真假结果互换。 观察完恢复原来的比较值。

接着在同一页试试年龄输入框。即使设置了 type="number"，输入 16 后，.value 读到的也是字符串 "16"。 脚本已把它存进 nianLingZhi。在 app.js 的 // 01 · 比较两种等号 下方写两行，把读到的值分别用 == 和 === 与数字 16 比较。

// 宽松比较会把年龄字符串转成数字，显示比较结果。
kuanSongJieGuo.textContent = nianLingZhi == 16;
// 严格比较保留年龄字符串的类型，显示比较结果。
yanGeJieGuo.textContent = nianLingZhi === 16;
  • = 把右边的值存到左边。两行代码都用它把比较结果写到网页上。
  • == 是宽松相等。类型不同时，它可能先转换再比较。本题会把字符串 "16" 转成数字 16 再比较。
  • === 是严格相等。类型和值都相同才为真。本题左边是字符串，右边是数字，结果为假。

保存并刷新。在年龄输入框里分别输入 16 和 17，每次先猜，再点「比较年龄」。

输入年龄 读到的值 == 16 === 16
16 "16" true false
17 "17" false false

再把第二行的 === 16 改为 === "16"，保存刷新后输入 16 并点「比较年龄」。 这次两个结果都是 true。严格比较的两边现在都是字符串 "16"。观察完恢复 === 16。

常见错误

  • 带引号的 "youDianJiChu" 是选项里的文字。直接写 youDianJiChu 表示存放真假的变量。

02 判断报名资格

机器人社要求「周三能来」并且「有点基础」。脚本已算好两个真假值。 zhouSan 表示选中的是不是周三，youDianJiChu 表示是否有点基础。

中文伪代码

如果 周三能来 并且 有点基础
  显示「可以报」和理由
否则如果 周三不能来
  说明机器人社在周三活动
否则
  说明机器人社需要有点基础

编写代码

  1. 在 app.js 的 // 02 · 组合条件 下方写第一行，把两项合起来。
// 周三能来且有点基础，报名资格才为真。
const nengBao = zhouSan && youDianJiChu;

&& 读作「并且」。两边都为 true 时，nengBao 才是 true。

  1. 紧接着写判断链。if (nengBao) 处理通过，else if (!zhouSan) 处理周三不能来， else 处理剩下的情况。三个分支都用 jieGuo.textContent 更新结果区。
// 报名资格为真，进入这个分支。
if (nengBao) {
  // 在结果区显示可以报名，并给出理由。
  jieGuo.textContent = "可以报。周三能来，而且有点基础。";
// 报名资格为假时，先检查是不是周三不能来。
} else if (!zhouSan) {
  // 告诉用户哪个活动日没对上。
  jieGuo.textContent = "不能报。机器人社在周三活动。";
// 周三能来却没通过，说明基础不符合要求。
} else {
  // 在结果区说明缺少哪项基础条件。
  jieGuo.textContent = "不能报。机器人社需要有点基础。";
// 报名资格判断结束。
}

运行检查

能来的时间 基础 点击「判断资格」后的结果
周三 有点基础 可以报。周三能来，而且有点基础。
周三 零基础 不能报。机器人社需要有点基础。
周一 有点基础 不能报。机器人社在周三活动。
周一 零基础 不能报。机器人社在周三活动。

常见错误

  • 如果只满足一项也通过，检查是否把 && 写成了 ||。|| 允许两项里至少一项成立就通过。
  • 两项都不满足时，本题先告诉用户活动时间。把缺基础的分支放在前面会改变这组测试的提示。

03 按顺序推荐

时间可以多勾几天。复选框的 .checked 是当前有没有勾选，直接得到真假值。 脚本已经用它读好 zhouYi（周一）、zhouSan（周三）、zhouWu（周五）。 youDianJiChu 表示基础下拉框选的是不是「有点基础」。 同一个人可能同时符合几家社团。按下面的顺序，找到第一个满足的条件就停。

中文伪代码

如果 周三能来 并且 有点基础，推荐机器人社
否则如果 周五能来，推荐合唱团
否则如果 周一能来，推荐篮球社
否则，显示「暂时没有匹配的社团」

编写代码

  1. 在 app.js 的 // 03 · 按顺序推荐 下方写一条判断链。用 if 写第一条， 用两个 else if 写中间两条，最后用 else 处理都没命中。
  2. 条件成立时用 = 把对应的社团名存进 tuiJian， 都没命中时存入空字符串 ""。预置的 xianShiTuiJian(tuiJian) 会根据你给的值显示对应卡片，或显示「暂时没有匹配的社团」。
// 先检查周三能来、同时有点基础。
if (zhouSan && youDianJiChu) {
  // 把机器人社记为要显示的推荐。
  tuiJian = "机器人社";
// 上一条不成立时，检查周五能不能来。
} else if (zhouWu) {
  // 把合唱团记为要显示的推荐。
  tuiJian = "合唱团";
// 前两条都不成立时，检查周一能不能来。
} else if (zhouYi) {
  // 把篮球社记为要显示的推荐。
  tuiJian = "篮球社";
// 前面三条都不成立，走到「否则」。
} else {
  // 存入空字符串，供显示函数提示暂无匹配。
  tuiJian = "";
// 推荐判断结束，后面的显示函数会读取 tuiJian。
}

运行检查

勾选时间 基础 点击「看推荐」后的结果
周三、周五 有点基础 只显示机器人社，理由提到周三和有点基础
周三、周五 零基础 只显示合唱团，理由提到周五
周一 零基础 只显示篮球社，理由提到周一
周三 零基础 显示「暂时没有匹配的社团」，没有卡片

再试顺序对调。把 if 改为判断 zhouWu 并写入合唱团， 把第一个 else if 改为判断 zhouSan && youDianJiChu 并写入机器人社。 保存后重试第一行，页面只推荐合唱团。观察后恢复原顺序，连点五次核对卡片数量仍是 1。

常见错误

  • 写成三个独立的 if 时，后面成立的分支还会执行，可能覆盖前面写好的社团。
  • 都没命中时，留给显示函数的值应当是 ""。显示函数用它决定何时显示「暂时没有匹配的社团」。

04 缺项先提示

网页要先知道年级和能来的时间。点一次按钮，可能两组都漏选，也可能只漏选一组。 这时应把每个提示写到对应问题下面。两组填好后才判断时间是否符合本题的报名规则。

biaoDan.querySelector('input[name="nianJi"]:checked') 在表单里找选中的年级。 [name="nianJi"] 限定年级组，:checked 限定选中的单选框。 找不到元素时得到 null，表示这一次没有选中年级。 脚本已算好 queNianJi（没选年级）和 queShiJian（没选时间）。 每次点击时，脚本先清空旧提示和结果，再执行你写的判断。

中文伪代码

如果 没选年级，在年级下方写提示
如果 没选时间，在时间下方写提示
如果 两项里至少漏选一项，结束本次检查

编写代码

在 app.js 的 // 04 · 缺项提示 下方， 分别用两个 if 处理年级和时间。两个判断各做各的，两项都少时两条提示都能写出来。 最后用 || 检查是否至少缺一项。有缺项就用 return 结束这一次点击处理。

// 年级没选时，执行下面的提示。
if (queNianJi) {
  // 在年级选项下面写一条提示。
  nianJiTiShi.textContent = "请先选年级。";
// 年级检查结束，接着检查时间。
}
// 时间没选时，执行下面的提示。
if (queShiJian) {
  // 在时间选项下面写一条提示。
  shiJianTiShi.textContent = "请至少选一个能来的时间。";
// 时间检查结束，两处提示都已检查完。
}
// 年级或时间少一项，就进入这个分支。
if (queNianJi || queShiJian) {
  // 结束本次点击处理，先等用户补齐。
  return;
// 两项都填好了，才继续下面的资格判断。
}

运行检查

  1. 两组保持空白，点「检查报名条件」。年级和时间下方各出现一条提示，结论区是空的。
  2. 只选高二再点。年级提示消失，时间提示仍在，结论区还是空的。
  3. 勾周一再点。两个提示都消失，结论是「不能报。活动安排在周三。」改勾周三再点，得到「可以报。周三能参加活动。」
  4. 取消时间选择再点。时间提示重新出现，上一次的「可以报」已清掉。
  5. 点「重置」后，原输入和提示清空，结论区显示「还没判断」。再直接点检查，看到步骤 1 的结果。

常见错误

  • 第二条提示写成 else if 时，年级缺项会抢先执行，时间漏选就没有提示。
  • 页面先显示提示又马上写出结论，检查 return 有没有写在资格判断之前。
