S9-1 · 资格条件

  1. 摆好年级、时间、基础、想报社团四组问题。
  2. 点按钮后先核对四组读到的值。
  3. 先只判时间，分别做一次通过和不通过。
  4. 加上基础要求，换三种组合核对结论和原因。

S9-2 · 推荐结果

  1. 在结果下面准备三张社团卡。
  2. 用一条判断链决定推给谁。
  3. 理由引用勾选的时间或基础。
  4. 切换输入，核对只见一张卡或一句暂无匹配。

S9-3 · 边界提示

  1. 空着点，核对提示是否贴在对应字段下面。
  2. 故意让时间冲突，读一遍改选建议。
  3. 重置后直接判断，再补全连点，检查有没有旧结果。
  4. 统一提示的位置和样式，切换输入核对主提示。
